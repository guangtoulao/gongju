      它怎么工作：抓取目标站首页，识别它用的苹果CMS 前端主题（myui / stui / fed / hl / module / 短视频），
      套你 模板.js 里对应的选择器骨架生成明文 drpy2 rule；云朵 / App 类加密站则走 csp_App3Q 风格条目。

      用法：① 把 rule 文件下载后放进 TVBox 配置目录的 lib/（与 drpy2.min.js 同级）；
      ② 把 site 条目粘进对应 *.json 的 sites 数组。绝大多数标准站套模板即可用，个别路径差异需在 TVBox 里微调 url/searchUrl。
    


    

      提示：云朵类条目里的 finger / sk / updateId 需按该站抓包填；确保你的 custom_spider.jar 已内置 App3Q。
